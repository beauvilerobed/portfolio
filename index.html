Case studies from my work

eParts · Regression

Pricing shipping from item-level costs

$13 → $4 median price error

Problem
Shipping prices missed actual carrier cost by $13 at the median, because cost was only recorded per bulk order.
Approach
Built SQL training tables that broke bulk orders into item-level costs, fit a regression model, and served it as an API on Azure.
Result
Median price error fell from $13 to $4 on standard orders while contribution margin held.

Limetree · Experimentation

Measuring experiments to guide budgets

−20% metric variance

Problem
Campaign tests were noisy, so real effects took too long to detect and budgets were hard to defend.
Approach
Built an in-house analysis platform that automated power analysis, significance tests, and A/B test readouts, with CUPED variance reduction.
Result
CUPED cut metric variance 20%, narrowing confidence intervals so the same test reaches a decision with a smaller sample.

Limetree · Predictive modeling

Lead scoring that improved targeting

+9% gross lead rate (relative)

Problem
Direct-mail campaigns reached many prospects unlikely to respond, so spend went to the wrong people.
Approach
Built an XGBoost lead-scoring model on millions of healthcare consumer records with hundreds of attributes, raising offline AUC-ROC and explaining drivers with SHAP.
Result
In an A/B test, targeting with the model raised gross lead rate 9% (relative).

AniPoint · Causal inference

The true lift of a new location

$533K average revenue per added site

Problem
How much new revenue can a market absorb? One more location adds sales, but some are taken from existing sites.
Approach
Double ML on a county-level panel, cross-checked with a Callaway–Sant’Anna difference-in-differences and a synthetic-data test that had to recover a known effect.
Result
On average, about $533K per added site (95% CI $390K–$676K), close to the DiD’s $472K. Sample analysis →
