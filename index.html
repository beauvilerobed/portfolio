Case studies

eParts · Regression

Pricing shipping from item-level costs

$13 → $4 median price error

Problem
Shipping prices missed actual carrier cost by $13 at the median, because cost was only recorded per bulk order.
Approach
Built SQL training tables that broke bulk orders into item-level costs, fit a regression model, and served it as an API on Azure.
Result
Median price error fell from $13 to $4 on standard orders while contribution margin held.

Limetree · Experimentation

Faster, more sensitive A/B tests

−20% metric variance

Problem
Campaign tests were noisy, so real effects took too long to detect.
Approach
Built an in-house experimentation tool with power analysis, CUPED variance reduction, and significance tests.
Result
CUPED cut metric variance 20%, so the same test reaches a decision with a smaller sample.

Limetree · Metrics & prediction

A leading indicator for enrollment

60 days of early warning

Problem
Enrollment results arrived long after a campaign, and teams used conflicting definitions of gross lead rate (GLR).
Approach
Standardized the GLR definition with data engineering, then tested out of sample whether it predicts later enrollment.
Result
GLR predicted enrollment rate 60 days ahead (R² = 0.49). A retrained XGBoost lead-scoring model (AUC 0.62 to 0.67) then raised GLR 9% in an A/B test.

AniPoint · Causal inference

The true lift of a new location

$533K revenue per added site

Problem
How much new revenue does one more car wash add to a county, net of sales taken from existing sites?
Approach
Double ML on a 234-county panel, cross-checked with a Callaway–Sant’Anna difference-in-differences and a synthetic-data test that had to recover a known effect.
Result
About $533K per added site (95% CI $390K–$676K), close to the DiD’s $472K. Sample analysis →
